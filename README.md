# call-transcript

Скилл для AI-агентов: делает транскрипт созвона из видео или аудио и размечает, кто
говорит. Русский, украинский и их смесь: каждая фраза остаётся на том языке, на котором
её сказали.

Работает в Claude Code, Codex, Hermes, Gemini CLI, Cursor, OpenCode, GitHub Copilot и
других агентах, которые понимают открытый формат [Agent Skills](https://agentskills.io).

Кидаешь агенту файл записи, минут через 15 в «Загрузках» лежит `.md`:

```markdown
# Созвон с Олегом 14.03.26: план сайта

Запись: 0:52:40. Голоса: я (рассказываю о проекте) и Олег (задаёт вопросы). Говорят по-русски.
...

**[12:04] Я:** Смотри, я главную страницу собрал так, чтобы...

**[13:40] Олег:** Понял. А форма заявки где будет?
```

## Чем это лучше, чем просто прогнать через Whisper

Whisper хорошо распознаёт речь, но на записи созвона он регулярно:

- молча пропускает 15-25 секунд живой речи или пишет три случайных слова на 14 секунд;
- выдумывает на тишине: «Продолжение следует...», «Субтитры сделал DimaTorzok»,
  «Дякую за перегляд!»;
- выравнивает смесь языков в один: русскую фразу в украинском созвоне пересказывает
  по-украински;
- теряет или добавляет «не», и смысл переворачивается;
- не знает, кто говорит.

Скилл находит такие места и распознаёт их заново короткими отрывками, убирает
выдумки, правит ослышки по смыслу и словарю, а говорящих размечает по смыслу
разговора. В шапке файла честно написано, что исправлено и где уверенности нет.

## Режимы

| | Обычный | Быстрый («сделай транскрипт быстро») |
|---|---|---|
| Распознаёт | Groq Whisper large-v3 | Soniox |
| Кто говорит | агент по смыслу | Soniox по голосу, агент даёт имена |
| Часовой созвон | 12-16 минут, смесь языков до 30 | 3-4 минуты |
| Стоит | Groq бесплатно, модель агента из твоей подписки | около 0,10 доллара за час звука у Soniox |

**Запасной движок.** Если Groq упёрся в лимит или не отвечает, куски распознаются на
твоём компьютере через whisper.cpp. Ставится по желанию, без него скилл тоже работает.

## Установка

Нужен Python 3.9 или новее (на Маке обычно уже есть).

1. ffmpeg:

   ```bash
   brew install ffmpeg
   ```

   На Linux: `sudo apt install ffmpeg`.

2. Скилл. Одна копия на все агенты, обновляется одной командой:

   ```bash
   git clone https://github.com/HinkoK/call-transcript ~/call-transcript
   mkdir -p ~/.agents/skills
   ln -s ~/call-transcript/skills/call-transcript ~/.agents/skills/call-transcript
   ```

   Из `~/.agents/skills` скилл сразу видят Codex, Gemini CLI, Cursor, OpenCode и GitHub
   Copilot. Claude Code и Hermes смотрят в свои папки, им нужна ещё одна ссылка:

   ```bash
   # Claude Code
   mkdir -p ~/.claude/skills
   ln -s ~/call-transcript/skills/call-transcript ~/.claude/skills/call-transcript

   # Hermes
   ln -s ~/call-transcript/skills/call-transcript ~/.hermes/skills/call-transcript
   ```

   В Hermes можно и без клона: `hermes skills install HinkoK/call-transcript/skills/call-transcript`.

   Обновить скилл: `git -C ~/call-transcript pull`.

3. Ключ Groq. Бесплатный, берётся на [console.groq.com/keys](https://console.groq.com/keys).
   Создай файл настроек и открой его:

   ```bash
   mkdir -p ~/.config/call-transcript
   touch ~/.config/call-transcript/.env && chmod 600 ~/.config/call-transcript/.env
   open -e ~/.config/call-transcript/.env
   ```

   Впиши строку и сохрани:

   ```
   GROQ_API_KEY=gsk_...
   ```

   Ключ не отправляй в чат агента: пусть лежит только в этом файле. Скилл читает его
   оттуда сам, в любом агенте.

4. По желанию, быстрый режим. Ключ на [console.soniox.com](https://console.soniox.com),
   туда же в `.env`:

   ```
   SONIOX_API_KEY=...
   ```

5. По желанию, запасной движок. whisper.cpp и модель large-v3 (1,1 ГБ):

   ```bash
   brew install whisper-cpp
   mkdir -p ~/.cache/call-transcript
   curl -L -o ~/.cache/call-transcript/ggml-large-v3-q5_0.bin \
     https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-q5_0.bin
   ```

Открой новую сессию агента, чтобы он увидел скилл.

### Codex и другие агенты с песочницей

Скрипту нужен интернет (Groq, Soniox) и запись в `~/Downloads`. Codex по умолчанию
не пускает команды в сеть и не даёт писать вне рабочей папки, поэтому на каждом
созвоне будет спрашивать разрешение. Это нормально: подтверждай.

Чтобы не спрашивал, добавь в `~/.codex/config.toml` (имя пользователя подставь своё):

```toml
[sandbox_workspace_write]
network_access = true
writable_roots = ["/Users/ИМЯ/Downloads"]
```

Учти: так сеть откроется для всех команд Codex, а не только для этого скилла.

## Как пользоваться

Просто попроси агента:

- «сделай транскрипт созвона ~/Downloads/созвон с Олегом 14.03.mp4»
- «расшифруй запись быстро ~/Downloads/встреча.m4a»
- «зроби транскрипт дзвінка ~/Downloads/дзвінок.mp4»

Явно вызвать скилл: `/call-transcript` в Claude Code и Hermes, `$call-transcript` в
Codex.

Имя собеседника скилл берёт из имени файла («созвон с Олегом» → «Олег») или из
разговора. Ты в транскрипте «Я».

Поправить разметку можно и потом, в любом новом разговоре: «в транскрипте созвона с
Олегом с 12:40 говорю я, а не он». Для этого скилл хранит рабочую папку.

**Где что лежит:**

- транскрипт: `~/Downloads/<имя записи> — транскрипт.md`;
- рабочая папка: `~/Downloads/.call-transcript/<имя записи>/` (скрытая). В ней звук
  записи и ответы распознавания. Когда поправки больше не нужны, удали её руками.

В конце агент называет 3-5 мест, где разметка говорящих менее надёжна. Их стоит
послушать.

## Приватность

- Обычный режим: звук уходит в Groq.
- Быстрый режим: звук уходит в Soniox. Скилл удаляет у Soniox и файл, и транскрипцию
  сразу после получения текста и проверяет, что их там больше нет. Если удаление не
  прошло, агент скажет об этом прямо.
- Совсем без отправки звука: `CALL_TRANSCRIPT_ENGINE=local` в `.env`, всё распознаёт
  whisper.cpp на компьютере. Текст созвона в любом случае читает модель агента.
- Рабочие файлы лежат в `~/Downloads`, а не в папке проекта: если проект в git, запись
  случайно не попадёт в коммит.

## Настройки

Все в `~/.config/call-transcript/.env` или в окружении.

| Переменная | Что делает |
|---|---|
| `GROQ_API_KEY` | ключ Groq, нужен для обычного режима |
| `SONIOX_API_KEY` | ключ Soniox, нужен для быстрого режима |
| `CALL_TRANSCRIPT_ENGINE` | `auto` (по умолчанию): Groq, при сбое локально; `groq`: только Groq; `local`: только локально |
| `CALL_TRANSCRIPT_LOCAL_MODEL` | путь к модели whisper.cpp, по умолчанию `~/.cache/call-transcript/ggml-large-v3-q5_0.bin` |
| `CALL_TRANSCRIPT_WHISPER_CPP` | команда whisper.cpp, по умолчанию `whisper-cli` |
| `CALL_TRANSCRIPT_TERMS` | свои имена и термины через запятую, подсказка для Soniox |

Агенты вроде Hermes передают командам не все переменные окружения, поэтому надёжнее
держать всё в файле `.env`.

Свои частые ослышки (название компании, жаргон) допиши в
`skills/call-transcript/references/mishearings.md`: агент сверяется с ним на каждом
созвоне.

## Запуск из своего бота или скрипта

Скилл работает и без окна агента. Пример для Claude Code:

```bash
claude -p "/call-transcript Сделай транскрипт созвона. Запись: \"$HOME/Downloads/созвон.mp4\". Вопросов не задавай." \
  --permission-mode dontAsk --permission-prompts none \
  --tools "Bash,Read,Write,Edit,Skill" \
  --allowedTools \
    "Bash(python3 ~/.claude/skills/call-transcript/scripts/call.py *)" \
    "Bash(python3 $HOME/.claude/skills/call-transcript/scripts/call.py *)" \
    "Bash(python3 $HOME/call-transcript/skills/call-transcript/scripts/call.py *)" \
    "Read(~/Downloads/**)" "Edit(~/Downloads/**)" \
    "Read(~/.claude/skills/call-transcript/**)" "Read(~/call-transcript/**)" "Skill(call-transcript)" \
  --add-dir ~/Downloads --output-format json
```

Так Claude может запускать только скрипт скилла (по ссылке и по настоящему пути клона) и писать только в `~/Downloads`.
Учти: разрешения из твоих общих настроек `~/.claude/settings.json` складываются с этими.
Если там есть что-то широкое вроде `Bash(python3:*)`, добавь `--setting-sources project`
и положи ссылку на скилл в `.claude/skills/` той папки, из которой запускаешь.

В других агентах смысл тот же: режим без окна, разрешены только скрипт скилла,
интернет и запись в `~/Downloads`.

Готовым транскрипт считай, только когда файл появился. Ответ агента «готово» сам по
себе не доказательство.

## Ограничения

- Если все голоса в одной дорожке, в обычном режиме говорящих агент определяет по
  смыслу. В коротких «да», «угу», «окей» бывают ошибки. Качество разметки зависит от
  модели: скилл собран и отлажен с Claude Opus.
- Обычный режим длинный: агент читает весь текст созвона и правит его по шагам. На
  часовой созвон с Claude Opus это около 3 долларов по ценам API или заметная часть
  лимита подписки.
- Настроен на русский и украинский. Английский распознаётся, но словарь ослышек
  русско-украинский.
- Проверялся на macOS (Apple Silicon). На Linux должен работать с теми же ffmpeg и
  whisper.cpp, но не проверялся. На Windows не проверялся.
- У бесплатного Groq есть лимит на секунды звука в час и в день. Короткие паузы скилл
  ждёт сам, при длинных уходит на запасной движок, если тот установлен.
