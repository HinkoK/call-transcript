# Ослышки Whisper, которые уже встречались

Подсказки, а не автозамена. Каждую пару проверяй в контексте: в `global` бери только
формы без другого смысла, остальное правь через `fix`. Новые подтверждённые пары
дописывай в конец своей группы с датой созвона. Имена и названия, которые встречаются
только у одного человека, сюда не пиши.

## Ловушки без словаря

Примеры ниже показывают тип ошибки, такие Whisper делает постоянно.

- Лишнее или потерянное «не»: «я не встигну» вместо «я встигну», «это не сложно»
  вместо «это сложно». Сверяй по второму прогону или отрывку.
- Слова, которые меняют факт: «два місяці» вместо «два місця», «пятнадцать» вместо
  «пятьдесят». Любые числа сверяй по второму прогону или отрывку.
- Глаголы, похожие по звучанию: «визначають» вместо «вивчають», «вивезти» вместо
  «вивести».
- Похожие слова с другим смыслом: «вставлять» вместо «оставлять», «отложить» вместо
  «отладить».
